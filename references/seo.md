# Technical SEO

- One unique `title` (about 50-60 characters) and `meta description` (about 150-160) per page, in pt-BR.
- One `h1` per page; logical heading order.
- `<html lang="pt-BR">`, `link rel="canonical"` with the final domain once known.
- Descriptive, short, lowercase URLs; internal links with meaningful anchor text.
- Open Graph and Twitter card tags (`og:title`, `og:description`, `og:image`, `og:url`, `og:locale` pt_BR). The share image must be a real asset.
- `sitemap.xml` and `robots.txt` when the site has more than one page or a known domain.
- Structured data (JSON-LD) only with real data (e.g. `LocalBusiness`, `Restaurant`); never invent ratings, prices or hours. Validate with Google's Rich Results Test when available.
- Images: descriptive file names and `alt`.
- Mobile friendly, fast, HTTPS. Pages must be indexable unless the user asks otherwise; use `noindex` on staging.
- Local businesses: consistent name, address and phone across the site, only when provided.
